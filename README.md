## ✨ Overview

Hover Expand Player keeps the interface intentionally small until the visitor interacts with it.

The compact state shows the artwork, track information, and animated equalizer. On hover, the player smoothly expands into a larger audio interface with playback progress, timing, playback controls, and volume.

The component is built specifically for Framer and exposes its core content, layout, styling, interaction, and animation settings through Framer property controls.

## 🧩 Framer Setup

1. Add the component to your Framer project.
2. Upload your audio through the **Music** property.
3. Add your album artwork.
4. Set the title and artist.
5. Adjust the player dimensions and visual style.
6. Preview the interaction and publish.

The component uses a compact default size of 230 × 60 and expands to 340 × 200 by default.

## ⌨️ Interaction

When expanded:

- Click **Play** to start or pause playback.
- Click **Restart** to return the track to the beginning.
- Click **Stop** to stop playback and reset the track.
- Click or focus the progress bar to control playback position.
- Use **Left / Right Arrow** to seek by 5 seconds.
- Use **Home / End** to jump to the beginning or end.
- Use the volume slider to control audio volume.

## ⚡ Performance & Accessibility

The component is designed with Framer usage in mind:

- Static rendering avoids active audio playback.
- Reduced-motion preferences are respected.
- Audio event listeners are cleaned up.
- Audio resources are cleaned up when the component unmounts.
- Progress controls expose slider semantics.
- Native buttons and range controls provide familiar keyboard interaction.
